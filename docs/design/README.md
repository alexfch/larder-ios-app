# Design Prototypes

Design work for Larder is prototyped in [Claude Design](https://claude.ai) and captured here as
versioned snapshots, so the visual history lives alongside the code it informs.

## Structure

- `exports/` — PNG snapshots of each design milestone, named `YYYY-MM-DD-<screen-or-flow>.png`
  (e.g. `2026-08-25-onboarding-flow.png`)
- Live, interactive versions are linked from the milestone table below when shared publicly

## Workflow

1. Design/iterate in Claude Design.
2. Export a PNG snapshot of the current state into `exports/`.
3. Add a row to the milestones table above; if the artifact is shared publicly, link it in the
   "Live Prototype" column.
4. Commit alongside any related code or PRD changes so history stays correlated.
